# Bundled typefaces

- Manrope variable (`Manrope-Variable.ttf`), downloaded from https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf . License: SIL Open Font License 1.1; see `Manrope-OFL.txt` (same Google Fonts source directory).
- DM Sans variable (`DMSans-Variable.ttf`), downloaded from https://github.com/google/fonts/blob/main/ofl/dmsans/DMSans%5Bopsz,wght%5D.ttf . License: SIL Open Font License 1.1; see `DMSans-OFL.txt` (same Google Fonts source directory).

Fonts ship with app. No runtime font service, download, or account-data request.
